## CanIDs
Directions of motor are when robot is intaking.
- **23**: Left Feeder/Vectoring Motor
  - Rotates *Clockwise*
- **24**: Right Feeder/Vectoring Motor
  - Rotates *Counter-Clockwise*
- **22**: Follower Roller/Magazine Motor
  - Rotates *Counter-Clockwise*
  - Follows **25**
- **25**: Main Roller/Magazine Motor
  - Rotates *Clockwise*
